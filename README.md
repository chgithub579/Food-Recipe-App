# Food Recipe App 🍽️

A modern **React-based Food Recipe Application** that allows users to search, browse, and explore meals from around the world. Recipes include **images, ingredients, step-by-step instructions, and video tutorials**.

## Features

- **Search Recipes**: Quickly find recipes by name.  
- **Alphabet Filter / Pagination**: Browse meals by first letter or page through multiple recipes.  
- **Recipe Details**: View recipe image, ingredients, instructions, and a YouTube cooking video in a neat, small container.  
- **Responsive UI**: Works smoothly on desktop and mobile devices.  
- **Clean & Professional Design**: Easy-to-read fonts, cards, and horizontal scroll for alphabets.
